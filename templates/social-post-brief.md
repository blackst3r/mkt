# 单条社媒素材发布包

收到视频或图片后，先记录可以直接看见或听见的内容，再为指定平台写发布稿。填好后可把下表交给排期同事。

| 字段 | 填写内容 |
| --- | --- |
| 素材与平台 | 素材名、时长或张数、发布账号与版位、目标受众 |
| 内容与目标 | 实际发生了什么？希望观众看完后做什么？ |
| 封面 | 视频填「时间点 + 构图 + 选它的原因」，图片填图号；检查目标版位裁切后主体是否仍完整 |
| 开头 | 写首屏文字或前两秒字幕；标明是拟加字幕还是原片对白 |
| 发布文案 | 可直接复制的标题、正文和适合该受众的一句行动提示，按平台及目标语言调整 |
| 时间 | 日期、北京时间、目标市场城市与当地日期和时间；跨日时写全两个日期，并核对当地夏令时 |
| 发布前核对 | 核对素材是否为最终版，文案中的价格、优惠和链接是否已确认 |

**虚构示例**　一个 12 秒的纸雕短片，第 4.6 秒第一次同时出现折叠前的平面和立起的纸鸟，两种状态在竖屏裁切后仍然可见，可选为封面。面向英语受众的开头字幕可用 “Watch the wings unfold.”，正文可以问 “Which color would you fold next?”。
